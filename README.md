# PumuiKit

쇼핑몰 장바구니를 **붙여넣거나**, 캡쳐 이미지를 **끌어다 놓으면**
`내용 / 규격 / 단위 / 수량 / 예상단가 / 예상금액` 표로 정리해 주고,
학교 품의서식 그대로 **엑셀(.xlsx)** 과 **CSV** 로 저장해 주는 도구입니다.

**서버도 API 키도 쓰지 않습니다.** 글자 인식, 표 정리, 엑셀 만들기가 전부 브라우저 안에서
돌아갑니다. 올린 캡쳐는 인터넷으로 나가지 않습니다.

## 쓰는 순서

1. **왼쪽 패널**에 장바구니 화면을 복사해 붙여넣습니다.
   - 캡쳐 이미지는 그 칸에 바로 <kbd>Ctrl</kbd>+<kbd>V</kbd> 해도 됩니다.
   - 이미지 파일을 패널 위로 끌어다 놓아도 됩니다.
2. **표로 정리하기** 를 누릅니다.
3. **오른쪽 표**에서 값을 직접 고칩니다. 합계는 즉시 다시 계산됩니다.
4. **품의서식 엑셀 저장** 또는 **CSV 저장**.

여러 번 눌러 여러 캡쳐를 이어붙일 수 있습니다(결과가 표 아래에 계속 쌓입니다).

## 만들어지는 엑셀

`품의서식참고.xls` 를 그대로 재현합니다.

| 열 | A | B | C | D | E |
|---|---|---|---|---|---|
| 머리글 | 내용 | 규격 | 수량 | 예상단가 | 예상금액 |
| 폭 | 32 | 12.5 | 6.3 | 10.4 | 10.5 |

- 머리글 굴림 9pt · 회색(C0C0C0) 채움, 본문 굴림 10pt
- 전 셀 가운데 정렬 · 실선 테두리 · 행 높이 17.4pt
- 예상금액은 값이 아니라 **수식**(`=C2*D2`)이라 엑셀에서 수량·단가를 고치면 따라 바뀝니다
- A4 세로, 여백 좌우 0.7" / 위아래 0.75", 머리글 행 인쇄 반복

체크박스 두 개로 조정할 수 있습니다.

- **단위 열 포함** — 참고 서식에는 `단위` 열이 없어 기본값은 꺼짐(5열)입니다. 켜면 6열로 나갑니다. CSV에는 항상 들어갑니다.
- **합계 행 붙이기** — 마지막에 `합계` 행(`=SUM(...)`)을 추가합니다. 기본값 켜짐.

> ExcelJS 로 만들 때 `<sheetViews>` 를 빼먹으면 엑셀이 행 높이를 통째로 무시합니다.
> `lib/xlsx.ts` 의 `views` 옵션은 지우지 마세요.

## 품목을 읽는 두 경로

| 입력 | 처리 |
|---|---|
| 붙여넣은 텍스트 | 규칙 파서 (`lib/parseCart.ts`) — 표(탭·엑셀 복사)와 줄글 장바구니를 모두 처리 |
| 캡쳐 이미지 | 브라우저 OCR(tesseract.js, 한글+영문) → 같은 규칙 파서의 **캡쳐 모드** |

캡쳐 모드는 인식 결과가 지저분하다는 것을 전제로 더 세게 걸러냅니다.

- 상품 사진 칸과 정보 칸이 한 줄로 붙어 나오므로, 공백이 8칸 이상 벌어진 곳에서 자릅니다.
- `배송비` · `적립혜택` · `후기 N건` 같은 말이 줄 **아무 데나** 있으면 그 줄을 통째로 버립니다.
  (자르기 전에 판정합니다. 먼저 자르면 `배송비` 라벨과 금액이 갈라져 배송비가 품목으로 새어 들어갑니다.)
- `h > Co`, `Hi 그`, `aa` 처럼 사진에서 나온 글자 조각을 버립니다.
- OCR은 `원`을 `8` · `2!` · `e#` 처럼 자주 잘못 읽으므로, 천 단위 쉼표가 있는 숫자도 가격으로 봅니다.
  (단, `1,000ml` · `1,000개`처럼 단위가 붙은 것은 제외)

그래도 상품명에 오타가 섞일 수 있어, 캡쳐로 만든 행에는 확인 안내가 함께 뜹니다.
**최종 확인은 사람이 합니다.**

## 로컬 실행

```bash
npm install
npm run dev
```

http://localhost:3000

`npm install` 이 끝나면 `scripts/setup-ocr.mjs` 가 tesseract.js 워커·WASM을
`public/tesseract/` 로 복사합니다(용량이 커서 저장소에는 넣지 않습니다).
한글·영문 인식 데이터(`public/tessdata/`, 약 3MB)는 저장소에 들어 있습니다.
덕분에 앱이 외부 CDN을 전혀 부르지 않아 학교망에서도 그대로 동작합니다.

## GitHub → Vercel 배포

```bash
git remote add origin https://github.com/<계정>/PumuiKit.git
git push -u origin main
```

[vercel.com](https://vercel.com) → **Add New… → Project** → `PumuiKit` 저장소 Import.
Next.js 로 자동 인식되고, **설정할 환경 변수도 서버 함수도 없습니다.**
모든 경로가 정적으로 만들어집니다.

## 구조

```
app/
  page.tsx              화면 전체 상태와 내보내기
components/
  InputPanel.tsx        붙여넣기 · 드래그앤드롭 · 첨부 목록
  ItemTable.tsx         편집 가능한 표와 실시간 합계
lib/
  parseCart.ts          장바구니 파서 (붙여넣기 모드 / 캡쳐 모드)
  ocr.ts                브라우저 OCR (tesseract.js, 자체 호스팅)
  image.ts              OCR 전처리 — 흑백 변환 + 글자 키우기(1600~2600px)
  xlsx.ts               품의서식 .xlsx 생성 (ExcelJS, 브라우저)
  csv.ts                CSV 내보내기 / 불러오기
scripts/
  setup-ocr.mjs         tesseract 워커·WASM 을 public 으로 복사
```

## 알아두면 좋은 점

- 첫 캡쳐를 읽을 때 인식 엔진과 한글 데이터를 한 번 불러옵니다(수 초). 이후에는 브라우저에 캐시됩니다.
- 캡쳐는 흑백으로 바꾸고 긴 변 1600~2600px로 맞춰 인식합니다. 작은 캡쳐는 오히려 키웁니다.
- 정가에 취소선이 있고 할인가가 따로 보이면 **할인가**를 단가로 씁니다.
- `10,000원 × 3개 = 30,000원` 처럼 합계가 함께 보이면 단가 10,000 · 수량 3으로 되돌립니다.
- 배송비·쿠폰·적립금은 품목에서 뺍니다.
